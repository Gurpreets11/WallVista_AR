# Wall Vista AR

We integrated OpenCV into the Android project and configured native .so libraries successfully.
Set up sample texture images (brick, wood, marble, etc.) inside assets for comparison.
Designed the image processing flow using grayscale conversion, blur, edge detection, and ORB feature matching.
Implemented the logic to compare user-selected images with reference textures using BFMatcher.

** Key Points*

   - Integrated OpenCV SDK into Android project with native .so libraries
   - Configured Gradle and resolved dependency / large file issues
   - Added sample texture images (brick, wood, marble, etc.) in assets
   - Implemented image processing pipeline (grayscale, blur, edge detection)
   - Applied ORB feature detection and descriptor extraction
   - Used BFMatcher for feature comparison and best-match selection
   - Designed basic UI for image selection, processing, and result display
   - Structured project for future real-time camera detection enhancement
